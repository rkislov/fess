GeoIP (GeoLite2-Country.mmdb) для Fence
=========================================

Файл нужен шлюзу waf-gateway для поля country_code в журнале соединений и карты стран в дашборде.

Способ 1 — UI (рекомендуется в Docker Compose)
-----------------------------------------------

1. Откройте в панели раздел **«Антивирус / Malware»** → блок **«GeoIP»**.
2. Либо вставьте **HTTPS-ссылку** на скачивание MMDB (например прямая ссылка MaxMind с ключом в query) и нажмите **«Скачать по URL»**,
   либо нажмите **«Выбрать .mmdb»** и загрузите файл **GeoLite2-Country.mmdb**.
3. policy-api сохраняет файл в том же каталоге, что читает waf-gateway; после успешной установки шлюз подхватывает базу по Redis без перезапуска.

Способ 2 — вручную (без UI)
---------------------------

Положите **GeoLite2-Country.mmdb** в каталог, заданный **FENCE_GEOIP_DATA_DIR** (по умолчанию в образе **/var/lib/fence/geoip**),
и убедитесь, что **GEOIP_MMDB_PATH** у waf-gateway указывает на этот файл. В **deploy/docker-compose.yml** используется общий том **fence_geoip_data**.

Регистрация MaxMind: https://www.maxmind.com/ — раздел GeoLite2.
