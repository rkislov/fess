# Security Feed: онлайн и офлайн

По подписке в кабинете https://feed.kislovs.ru/cabinet доступны два ZIP:

- IOC: IP/CIDR, MD5, SHA-1, SHA-256, домены, URL и Spamhaus ASN/CIDR.
- IOC + ClamAV: те же IOC и main.cvd, daily.cvd, bytecode.cvd.

В FESS откройте IOC → «Ручная загрузка TXT / ZIP» и выберите архив целиком.
Сначала проверяются формат, размеры, количество записей и SHA-256 каждого
файла. Затем все категории IOC заменяются одной транзакцией. Ошибка проверки
оставляет предыдущий снимок. Старый TXT-импорт IP/CIDR сохранён.

Домены и полные URL сохраняются для корреляции и учитываются в статистике.
Блокировка шлюза применяется к IP/CIDR и хэшам тела запроса; домены и URL
автоматически не превращаются в IP-блоклисты. Регистр пути, параметры и
фрагменты URL сохраняются. SHA-1 участвует в сопоставлении хэшей наряду с
MD5 и SHA-256.

Полный архив также устанавливает CVD в `/var/lib/fess-clamav` и отправляет
RELOAD локальному clamd. Перед заменой подготавливаются все три базы;
при сбое транзакции IOC восстанавливаются прежние файлы. Альтернативные
`.cld` для этих баз убираются при успешной замене, чтобы избежать дублей.
Для нестандартного каталога задайте `FESS_CLAMAV_DATABASE_DIR` и разрешите
запись в него в systemd. Пакеты FESS предоставляют группе fess-av запись
только в каталог баз. Перед ручным импортом рекомендуется приостановить
freshclam, чтобы два процесса не меняли базы одновременно.
Контрольные суммы проверяют целостность переноса; цифровой подписью архива
они не являются. Используйте архив из доверенного личного кабинета.

## Онлайн

В IOC выберите «FESS Feed», укажите `https://feed.kislovs.ru` и API-ключ
подписки. При синхронизации скачивается один снимок всех включённых
источников через `/feeds/v1/offline.zip`, без отдельных ключей поставщиков
и без фильтрации старым полем sources. Категории не расходятся по времени.
Неудачное скачивание или проверка сохраняет последний снимок.
Автоматическое обновление действует при сохранённом ключе подписки даже
при отключённой проверке IOC шлюзом; интервалы и дневной лимит сохраняются
(не чаще 12 часов, до двух автоматических обновлений в сутки).

ClamAV доступен без подписки. В `/etc/fess/freshclam.conf` укажите:

```
PrivateMirror https://cvd.kislovs.ru
```

Затем перезапустите `fess-freshclam`. Зеркало поддерживает HEAD, Range и
If-Modified-Since для проверки версий без загрузки всей базы.
В настройках Malware URL зеркала формирует директиву PrivateMirror для
cvd.kislovs.ru. Онлайн-обновление ClamAV выполняет freshclam независимо
от подписки и расписания IOC.

Панель установленного сервиса: https://fess.kislovs.ru (обычная авторизация FESS).

## Spamhaus ASN/CIDR

Feed обновляет официальный ASN-DROP и DROP IPv4/IPv6. В архив входят
`asns.txt` и `bot-cidrs.txt`. При импорте FESS заменяет соответствующие
списки защиты от ботов в той же транзакции, что и IOC, обновляет статистику
и уведомляет работающий шлюз. При использовании подписки это происходит
автоматически; ручные ASN/CIDR-файлы при следующей синхронизации заменяются
списками подписки. Настройки включения блокировки ASN/CIDR сохраняются.
Старый архив без обоих файлов не очищает существующие ручные списки.
Подписные TXT: `/feeds/v1/asns.txt` и `/feeds/v1/bot-cidrs.txt`.
Источник: https://www.spamhaus.org/blocklists/do-not-route-or-peer/.
